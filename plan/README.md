## 🚀 使用方法

1. **每天打开 [06-每日详细任务.md](./06-每日详细任务.md)**，找到当天日期
2. 按「阅读任务 → 听力任务 → 输出任务」顺序执行
3. 完成后在 [02-每日打卡表.md](./02-每日打卡表.md) 记录
4. 写邮件时参考 [04-邮件模板库.md](./04-邮件模板库.md)
5. 遇到不懂的术语查 [05-后端技术词汇表.md](./05-后端技术词汇表.md)
