# 38岁后端程序员海外接活英语学习计划

> 12周系统化英语学习计划，专为有一定技术基础、希望通过 Upwork/Toptal 等平台承接海外项目的后端开发者设计。

## 📋 计划概览

| 阶段 | 时间 | 核心目标 | 每日时长 |
|---|---|---|---|
| **阶段一：读写突破** | 第1-4周 | 技术文档流畅阅读 + 专业邮件写作 | 70min |
| **阶段二：听说突破** | 第5-8周 | 客户会议无障碍 + 平台实战接单 | 70min |
| **阶段三：商务谈判** | 第9-12周 | 报价谈判 + 全流程英文沟通 | 60-70min |

**起始日期**：2026-09-14（周一）
**结束日期**：2026-12-06（周日）
**总天数**：84天

## 🎯 三阶段详细计划

### 阶段一：读写突破（第1-4周）

**目标**：能流畅阅读英文技术文档，独立撰写专业邮件和技术博客。

| 周次 | 主题 | 核心任务 | 里程碑 |
|---|---|---|---|
| 第1周 | 建立节奏+技术文档阅读 | PostgreSQL/Redis官方文档精读 + 邮件模板积累 | 连续7天不间断 + 3个邮件模板 |
| 第2周 | 邮件写作+技术词汇体系 | K8s/AWS文档 + 10个邮件模板 + 50个后端词汇 | 发布第1篇英文技术博客 |
| 第3周 | 听力突破+博客持续输出 | Martin Fowler博客 + 影子跟读 + 无字幕听力 | 10个邮件模板 + 第2篇博客 |
| 第4周 | 阶段复盘+读写能力验收 | DDIA书籍精读 + 阶段测试 + 总结 | 不查词读完中等难度技术文章 |

### 阶段二：听说突破（第5-8周）

**目标**：能独立完成30分钟英文客户会议，在海外平台投标并获得回复。

| 周次 | 主题 | 核心任务 | 里程碑 |
|---|---|---|---|
| 第5周 | 影子跟读+口语输出启动 | 每天影子跟读 + 自言自语练习 + 第一次外教课 | 7天影子跟读 + 第1次外教对话 |
| 第6周 | Upwork平台注册+Profile完善 | 注册Upwork/Toptal + 英文Profile + 作品集 | Profile 100%完成 |
| 第7周 | Proposal写作+首次真实对话 | 每天写2份Proposal + 外教课 + 客户沟通表达 | 累计4次真实对话 + 3种Proposal模板 |
| 第8周 | 真实投递+阶段复盘 | 真实投递3-5份Proposal + 听力测试 + 总结 | 获得至少1次客户回复 |

### 阶段三：商务谈判（第9-12周）

**目标**：能独立处理客户谈判、合同沟通、争议处理，稳定获得海外客户。

| 周次 | 主题 | 核心任务 | 里程碑 |
|---|---|---|---|
| 第9周 | 商务英语精听+谈判表达 | HBR/Acquired商务听力 + 谈判表达库 + LinkedIn动态 | 30+谈判句型 + 第1篇LinkedIn动态 |
| 第10周 | 模拟谈判+个人品牌建设 | 模拟谈判 + GitHub英文README + 技术博客 | 10个高频问题标准答案 + 英文README完善 |
| 第11周 | 实战接单准备+全流程演练 | 接单手检查清单 + 合同术语 + 模拟kickoff + 真实投递 | 全流程英文沟通模拟通过 |
| 第12周 | 总复盘+下一阶段规划 | 12周总结 + 成果清单 + 下阶段计划 | 接到第一个海外付费项目（目标） |

## 📅 每日任务结构

每个工作日包含三项核心任务（约70分钟）：

### 1. 技术阅读（30分钟）
- 从官方文档/技术博客中选取具体文章
- 第一遍不查词抓大意，第二遍查关键词
- 摘抄5个实用句型

### 2. 听力输入（20分钟）
- 技术播客/YouTube视频
- 阶段一：开字幕听 → 脱字幕听
- 阶段二：影子跟读（逐句模仿语音语调）
- 阶段三：商务英语精听

### 3. 输出任务（20-40分钟）
- 阶段一：写邮件模板/技术博客
- 阶段二：口语练习/Proposal写作/外教课
- 阶段三：谈判表达/模拟对话/个人品牌建设

**周末任务**（90-120分钟）：写技术博客、阶段复盘、外教课、平台实操。

## 🔤 后端高频技术词汇（精选）

### API与协议
- **RESTful API** - REST风格接口
- **endpoint** - 接口端点
- **payload** - 请求/响应体数据

- **WebSocket** - 全双工通信协议
- **rate limiting** - 限流
- **pagination** - 分页

### 数据库
- **ACID** - 事务四大特性
- **transaction** - 事务
- **index** - 索引
- **query optimization** - 查询优化
- **N+1 problem** - N+1查询问题
- **migration** - 数据库迁移
- **replication** - 主从复制
- **sharding** - 分库分表

### 架构与设计
- **microservices** - 微服务
- **monolith** - 单体架构
- **distributed system** - 分布式系统
- **scalability** - 可扩展性
- **load balancing** - 负载均衡
- **circuit breaker** - 熔断器
- **single point of failure** - 单点故障
- **event-driven** - 事件驱动

### 缓存与消息队列
- **cache** - 缓存（cache hit/miss）
- **in-memory** - 内存级

### 部署与运维

- **deployment** - 部署（rolling/blue-green）

### 性能与优化
- **latency** - 延迟（p99 latency）
- **throughput** - 吞吐量
- **bottleneck** - 瓶颈
- **profiling** - 性能分析

### 安全
- **authentication** - 认证

## 📧 邮件模板库（10个高频场景）

1. **初次接触/自我介绍** - 一句话定位 + 核心技能 + 项目经验 + 合作意愿
2. **报价/Proposal** - 理解需求 + 技术方案 + 时间报价 + 交付物 + 差异化
3. **需求确认** - 复述需求 + 待确认问题 + 提出假设 + 确认后开工
4. **进度更新** - 进度百分比 + 已完成 + 进行中 + 下一步 + 风险
5. **催款** - 友好开场 + 发票信息 + 付款期限 + 询问问题 + 付款方式
6. **项目交付** - 宣布完成 + 交付物清单 + 使用说明 + 请求验收 + 后续支持
7. **延期说明** - 直接说明 + 原因 + 新时间 + 已采取措施 + 道歉承诺
8. **范围变更** - 确认收到 + 是否在范围内 + 额外工作量 + 追加报价 + 等待确认
9. **砍价回应** - 表示理解 + 定价依据 + 替代方案 + 不降价格降范围 + 保持专业
10. **拒绝不合理需求** - 感谢反馈 + 不可行原因 + 替代方案 + 方案好处 + 合作态度

## 🚀 使用方法

### 每日执行流程
1. 打开 Excel 文件「每日详细任务」sheet，找到当天日期
2. 按「阅读任务 → 听力任务 → 输出任务」顺序执行
3. 完成后在「每日打卡表」勾选，记录实际时长
4. 输出任务的成果保存到本地（邮件模板、博客草稿等）

### 每周复盘
- 对照「12周学习计划」的里程碑检查完成情况
- 整理本周学到的新词汇和句型
- 调整下周计划（如果某部分太难/太简单）

### 关键节点
- **第4周末**：阶段一验收，确认读写能力达标
- **第8周末**：阶段二验收，确认听说能力达标，开始真实投递
- **第12周末**：总复盘，目标是接到第一个海外项目

## ⚠️ 避坑提醒

1. **不要从背单词书开始** — 直接从技术文档和工作场景学，效率高10倍
2. **不要只输入不输出** — 读10篇不如写1篇，听10小时不如说10分钟
3. **不要等"学好了"再接单** — 第8周就开始投低价小单，实战是最好的老师
4. **不要追求完美发音** — 流利度和清晰度比口音重要
5. **不要忽视文化差异** — 海外客户更看重直接沟通、准时交付、主动同步进度
