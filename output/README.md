# 学习产出目录

本目录用于存放学习过程中产生的所有产出文件。

## 📁 目录结构

| 目录 | 内容 | 对应计划 |
|---|---|---|
| [`email-templates/`](./email-templates/) | 10个 freelancer 高频邮件模板 | 第1-4周 |
| [`blog-posts/`](./blog-posts/) | 英文技术博客草稿与发布记录 | 每周末 |
| [`proposals/`](./proposals/) | Upwork/Toptal Proposal 模板与实战 | 第6-8周 |
| [`vocabulary/`](./vocabulary/) | 后端技术词汇笔记与造句练习 | 持续积累 |

## 📝 使用方法

1. **每天完成输出任务后**，将产出保存到对应目录
2. **邮件模板**：先复制模板文件，再根据具体场景修改
3. **博客草稿**：用 Markdown 写作，完成后发布到 [Dev.to](https://dev.to/) 或 [Medium](https://medium.com/)
4. **Proposal**：每次投递前复制模板，针对客户需求定制
5. **词汇笔记**：遇到生词随时记录，每周复习一次
