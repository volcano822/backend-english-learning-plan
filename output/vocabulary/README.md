## 🎯 学习方法

1. **每天学5个新词**：从阅读材料中摘抄，不要孤立背单词
2. **每个词造一个句子**：用自己的工作场景造句，记得牢
3. **每周复习**：周末复习本周学的所有词汇
4. **在输出中使用**：写邮件/博客时刻意使用新学的词汇
5. **听力中识别**：听播客/视频时注意听学过的词汇
