# 邮件模板库（10个 Freelancer 高频场景）

> 使用方法：复制对应模板，替换 `[方括号]` 中的内容为你的实际信息。

---

## 1. 初次接触 / 自我介绍


## 📝 使用建议

1. **个性化**：每个模板都要根据你的实际情况修改，不要直接复制粘贴
2. **简洁**：客户时间宝贵，邮件尽量控制在200词以内
3. **专业**：用 [Grammarly](https://www.grammarly.com/) 检查语法和拼写
4. **及时**：客户邮件尽量在24小时内回复
5. **存档**：每次发送的邮件都保存一份，方便后续参考
